# LINE OA เป็นช่องทางหลัก เว็บเป็นช่องทางสำรองที่ทำได้เท่ากัน บน backend เดียว

นักศึกษาไทยไม่ค่อยเปิดอีเมล จึงให้ "พี่ฝึกงาน" อยู่ใน LINE OA เป็นหลัก แต่เจ้าของเคยเจอ LINE Messaging API ล่มจนบริการแชทใช้ไม่ได้ เราจึงทำเว็บ (`index.html`) ที่ทำได้ทุกอย่างเท่ากับ LINE และล็อกอินด้วยอีเมล + OTP โดยไม่พึ่ง LINE ตรรกะทั้งหมดอยู่ใน Cloudflare Worker ตัวเดียว (`worker/`) ซึ่งทั้ง LINE webhook และ Web API เรียกใช้ร่วมกัน ส่วนปุ่มทุกปุ่มวิ่งผ่าน `runCardAction` เพื่อให้สองช่องทางไม่มีวันทำงานต่างกัน

**ผลที่ตามมา:** ห้ามใส่ logic ในเบราว์เซอร์หรือแยกตามช่องทาง ฟีเจอร์ใหม่ต้องใช้ได้ทั้งสองช่องทาง ถือว่าล้มเหลวถ้า LINE ล่มแล้วเว็บทำบางอย่างไม่ได้ ที่มา: `docs/superpowers/specs/2026-11-11-line-primary-web-fallback-design.md`
