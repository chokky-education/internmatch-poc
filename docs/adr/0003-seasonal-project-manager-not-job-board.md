# เป็นผู้ช่วยฤดูฝึกงาน ไม่ใช่เว็บหางาน

เว็บหางานจบหน้าที่ตรงที่ผู้ใช้กดสมัคร ส่วน InternMatch อยู่ด้วยจนนักศึกษาได้เริ่มฝึกงาน หน้าแรกจึงตอบคำถามว่า "วันนี้ต้องทำอะไร" (บอร์ดใบสมัคร, เอกสารคณะ, เตือนวันสำคัญ) และรับงานจากทุกแหล่ง (URL, ภาพแคป, แชร์เข้า LINE) แทนการโชว์ประกาศจำนวนมาก การค้นหาฝึกงานจึงเป็นแค่ทางเข้าทางหนึ่ง ไม่ใช่หน้าหลัก และเราไม่วัดความสำเร็จจากจำนวนประกาศ

**ผลที่ตามมา:** อย่าเปลี่ยนหน้าหลักเป็นรายการประกาศ หรือเพิ่มฟีเจอร์ที่ทำให้แอปกลายเป็นตัวรวมประกาศ ที่มา: `PRD.md` §2
