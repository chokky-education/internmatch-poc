# เว็บและ API อยู่ origin เดียวกัน และ session ไม่ผ่าน JavaScript

เจ้าของอนุมัติการแก้ XSS และการเก็บ token พร้อมปล่อยระบบวันที่ 13 พฤศจิกายน 2569 จึงให้ Worker เดิมเสิร์ฟเฉพาะไฟล์หน้าเว็บที่เลือกไว้ควบคู่กับ API ที่ `https://internmatch-api.entrace-space.workers.dev/` เพื่อแยกจากแอปอื่นบน origin ร่วมของ GitHub Pages และใช้คุกกี้ first-party บน iPhone ได้ ลิงก์ Pages เดิมลบ `im_token` เก่าแล้วส่งต่อเฉพาะ fragment ไป origin คงที่ เว็บใช้คุกกี้ host-only `__Host-im_session; HttpOnly; Secure; SameSite=Lax; Path=/` เท่านั้น ไม่ส่ง session ใน JSON หรือรับ browser Bearer เก็บ D1 เป็น `v2:` ตามด้วย SHA-256 และทำให้ session รุ่นเก่าใช้ไม่ได้ คำขอเว็บที่เปลี่ยนข้อมูลต้องมี Origin ตรงกับทั้ง config และปลายทาง ส่วน LINE ยังคงตรวจลายเซ็นและใช้ backend/การ์ดชุดเดิม ทุก release ต้อง deploy Worker พร้อม asset manifest ของ merged SHA ก่อนเผยแพร่ Pages launcher และต้องตรวจ login/reload/logout/relogin รวมถึงการแสดงข้อมูลเป็นข้อความ ผลที่ตามมาคือผู้ใช้ล็อกอินใหม่หลัง cutover และคำสั่ง local development ต้องเสิร์ฟเว็บกับ API ที่ origin เดียวกัน โดยไม่เปลี่ยนข้อมูลฝึกงาน การผูก LINE หรืออายุ session 30 วันที่มีอยู่
