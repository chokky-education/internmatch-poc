# ไม่มีส่วนอาจารย์ / Admin / Approval

ผลิตภัณฑ์นี้ให้นักศึกษาใช้คนเดียว เวอร์ชันแรกเคยมีหน้า `pipeline` กับ Admin Portal ให้อาจารย์อนุมัติ แต่เราลบออกทั้งหมด และระบบไม่มีบทบาท admin เพราะ prototype นี้ทีมใช้เอง และ InternMatch ไม่อ้างว่ารู้สถานะของคณะได้อัตโนมัติ ไม่มีใครในระบบอนุมัติแทนคณะ

**ผลที่ตามมา:** ถ้าเห็น "Admin Portal" ใน `UI_UX_SPEC.md` หรือเอกสารเก่า ให้ถือว่าเลิกใช้แล้ว อย่าสร้างขึ้นมาใหม่
