# โจทย์และกลยุทธ์

ใช้เป็นแบบร่างก่อนเริ่มแคมเปญ แยกสิ่งที่รู้แล้วออกจากสมมติฐาน และเชื่อมกลับไปยังหลักฐานใน `../research/`

- โจทย์ที่ต้องการแก้:
- นักศึกษากลุ่มไหน/อยู่ช่วงใดของฤดูฝึกงาน:
- ปัญหาที่พบและหลักฐาน:
- วิธีที่เขาใช้อยู่ตอนนี้:
- คุณค่าที่ InternMatch ส่งมอบได้จริงในเวอร์ชันปัจจุบัน:
- เหตุผลที่เขาจะเลือกลอง:
- พฤติกรรมที่อยากให้เกิด:
- ข้อความหลักที่จะสื่อ:
- ช่องทางและเหตุผลที่เลือก:
- เงื่อนไขเข้าใช้และข้อจำกัดที่ต้องบอก:
- วิธีวัดผล/เกณฑ์ตัดสิน/ช่วงเวลา:
- เรื่องที่ยังไม่รู้และต้องตรวจต่อ:

สถานะเริ่มต้น: ยังไม่ได้กำหนดกลยุทธ์ กลุ่มเป้าหมายย่อย งบประมาณ หรือเป้าตัวเลข
