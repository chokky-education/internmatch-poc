# ข้อมูลลูกค้า

เก็บบทสัมภาษณ์ สิ่งที่สังเกต และคำถามที่ยังตอบไม่ได้ ตั้งชื่อไฟล์ `YYYY-MM-DD-topic.md` และเก็บเฉพาะข้อมูลที่จำเป็นโดยไม่ใส่ข้อมูลส่วนตัวของนักศึกษาใน repo สาธารณะ

## แบบบันทึก

- วันที่/วิธีเก็บข้อมูล:
- กลุ่มนักศึกษาและช่วงของฤดูฝึกงาน:
- สถานการณ์ที่เจอ:
- คำพูดจริงหรือสิ่งที่สังเกตได้ (ตัดข้อมูลระบุตัวบุคคล):
- ปัจจุบันเขารับมืออย่างไร:
- สิ่งที่เราตีความ — ยังต้องตรวจ:
- หลักฐานที่สนับสนุน/ขัดกับการตีความ:
- คำถามที่จะคุยต่อ:

ยังไม่มีผลสัมภาษณ์หรือข้อสรุปเรื่องลูกค้าในโฟลเดอร์นี้
