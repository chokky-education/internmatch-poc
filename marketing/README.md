# Marketing — InternMatch

พื้นที่ทำงานการตลาดของ InternMatch ตั้งแต่ทำความเข้าใจนักศึกษา วางกลยุทธ์ เตรียมคอนเทนต์ ไปจนถึงดูผลที่เกิดขึ้นจริง

เริ่มจัดพื้นที่วันที่ 14 พฤศจิกายน 2026 ยังไม่มีแคมเปญ งบประมาณ หรือกลยุทธ์ที่เจ้าของอนุมัติ

## เริ่มใช้

1. เก็บสิ่งที่ได้ยิน/เห็นจากนักศึกษาใน [ข้อมูลลูกค้า](research/README.md) แยกคำพูดจริงออกจากสิ่งที่เราตีความ
2. ใช้ข้อมูลนั้นเติม [โจทย์และกลยุทธ์](strategy/README.md) ก่อนเลือกช่องทางหรือทำคอนเทนต์
3. เตรียมงานใน [คอนเทนต์](content/README.md) และบันทึกสิ่งที่ลองพร้อมผลใน [การทดลอง](experiments/README.md)
4. อ่าน [บันทึกจากเอกสารตั้งต้น](references/marketing-strategy-behavioral-design.md) เมื่อต้องการกรอบช่วยคิด

## จุดตั้งต้นของผลิตภัณฑ์

InternMatch เป็น **ผู้ช่วยพานักศึกษาผ่านฤดูฝึกงาน** ช่วยดูว่าวันนี้ต้องทำอะไร ติดตามใบสมัคร เตรียมรายการเอกสาร และเตือนวันสำคัญ ใช้ LINE เป็นช่องทางหลักและเว็บทำงานต่อได้

ยึด [ข้อกำหนดผลิตภัณฑ์](../PRD.md), [การวางตำแหน่ง](../docs/adr/0003-seasonal-project-manager-not-job-board.md) และ [สถานะล่าสุด](../docs/STATUS.md) ก่อนนำข้อความไปใช้:

- หน้าค้นหายังใช้ประกาศตัวอย่าง จึงยังอ้างว่ามีฐานประกาศงานจริงไม่ได้
- รายการเอกสารเป็นสิ่งที่นักศึกษาเพิ่ม/รายงานเอง ยังไม่ใช่ฐานข้อกำหนดที่คณะรับรอง
- prototype จำกัดผู้เข้าใช้ตามอีเมลที่อนุญาต การชวนมาทดลองต้องบอกเงื่อนไขนี้

คำสัญญา ประโยชน์ และผลลัพธ์ในงานการตลาดต้องมีหลักฐานรองรับ ร่างในโฟลเดอร์นี้ยังไม่ใช่เนื้อหาที่อนุมัติให้เผยแพร่
