# คอนเทนต์

เก็บไอเดีย ร่าง และชิ้นงานที่ผ่านการตรวจ ตั้งชื่อไฟล์ `YYYY-MM-DD-channel-topic.md` และระบุสถานะ `ไอเดีย / ร่าง / รอตรวจ / อนุมัติ / เผยแพร่แล้ว`

## แบบเตรียมชิ้นงาน

- สถานะ/ผู้ตรวจ:
- เชื่อมกับโจทย์หรือกลยุทธ์ข้อไหน:
- คนอ่านและสถานการณ์:
- ข้อความเดียวที่อยากให้จำ:
- หลักฐานของคำกล่าวอ้าง:
- เนื้อหาร่าง:
- สิ่งที่ชวนให้ทำต่อ:
- ช่องทาง/รูปแบบ:
- เงื่อนไขเข้าใช้และข้อจำกัดของฟีเจอร์ที่กล่าวถึง:
- วันเผยแพร่/ลิงก์จริง (เติมเมื่อเผยแพร่แล้ว):

ยังไม่มีเนื้อหาที่อนุมัติให้เผยแพร่ การสร้างร่างไม่ได้รวมการอนุมัติให้โพสต์ ส่งข้อความ หรือซื้อโฆษณา
